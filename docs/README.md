# Documentación y evidencias del Proyecto Final

Esta carpeta contiene los anexos y evidencias del proyecto final.

## Estructura

- `diagrams/`: diagramas de dominio, módulos, paquetes y bounded contexts.
- `testing/`: evidencias de pruebas unitarias y pruebas funcionales Selenium.
- `performance/`: pruebas de rendimiento con JMeter.
- `security/`: evidencias de seguridad con OWASP ZAP.
- `jenkins/`: evidencias del pipeline CI/CD.
- `docker/`: evidencias del despliegue con Docker ([documentación](./docker/docker-despliegue.md)).
